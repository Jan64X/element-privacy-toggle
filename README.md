# Element.io privacy toggle

This userscript for element.io adds a button that can blur all your messages. This button toggles visibility - when turned on, messages are blurred unless you hover them. State is store in cookies.

## Why is it useful
The goal of this userscript is to protect your privacy when in a public setting, where you aren't comfortable with your whole chat history being visible for other people.

## Installation

### Browser

Get the userscript on [Greasy Fork](https://greasyfork.org/cs/scripts/595884-element-privacy-toggle).

### Element Desktop

1. Open [element-privacy-toggle.js](element-privacy-toggle.js), click **Copy raw file**.
2. In Element Desktop, open **DevTools** using **Ctrl+Shift+I** and select **Console**.
3. Paste the code into the console and press Enter.

Note: Unlike the userscript, you'll have to paste this in every time you start/reload Element Desktop.
